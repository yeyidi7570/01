# 结构支持清单

| 结构 | 样本中的呈现 |
| --- | --- |
| Lesson / Module | 保留 `content_order`，可打开整课或模块。跨页模块在其原书页上分别展示，续段仍指向同一个 Module ID。课内独立说明保留同级身份。 |
| Text / Other | 保留换行、段落和可识别的连续数字列表。带 `printed_algorithm_steps` 的算法步骤作为有序列表，保留原编号文字。 |
| Formula | 行内公式、续行等式、Unicode 上标、印刷空框。二维竖式读取 `vertical.layout` 的数位列、运算符、横线跨度、单位、留白和进借位标记。旧式 `vertical` 读取原操作数与单位字段，按最低单位对齐。读取 `printed_expression_grid.row_major_ids` 展示显式算式组。 |
| Table | 原生表格保留表头、行列、合并、空白、多行文字和原印缩写。时段按 `time_interval` 展示带下划线的上标分钟。 |
| Informative Image | 使用该对象的裁图和图示说明。引用图形中其它对象时可沿 ID 跳转，并显示已记录的方向和目标文字。照片、图形和公共裁图都从教材指定扫描坐标读取。 |
| Badge | 显示原文、位置对应的阅读顺序及 `scope_ids`，包括只覆盖子题的标签。 |
| Instructional Note | 展示原书说明标题、正文、公式与图示。课内用独立 ID 和独立版块表示。 |
| Subtask | 保留父 Module、原书编号和嵌套顺序，包括小写字母及跨页子题。 |
| Example | 保留子对象顺序，使用 `worked_sequence.steps`、`relationships` 和结构说明来呈现共享步骤及连续计算。 |
| 教学关联 | 保留 `supports`、`uses_as_material` 的方向及端点。教师视图显示教材记录的理由。 |
| 对象定位 | 支持教材内容 ID、表格单元格 ID 和教学关联 ID。扫描原件在「原书对照」查看。 |

## 不支持或部分支持

| 情形 | 呈现 |
| --- | --- |
| 未识别的对象、记法，或数据不完整的表格、竖式 | 显示「不支持的结构」及对象 ID。公式、表格和算例的扫描证据可以通过原书对照查看。 |
| 图表数据只在截图中，或信息图缺少资源、图示说明 | 显示「不支持的结构」。对具有正式图示裁图的 Informative Image，裁图和结构说明是可用的教材内容，警告描述无法重建为交互对象的部分。 |
| 算式网格、跨对象的箭头、括号或图文布局缺少明确字段 | 保留能读取的内容、顺序和关系，另在相关对象上标明缺口。样本位置与扩展建议见[验证报告](VALIDATION.md)。 |
| 长除法网格、复杂富文本和图表任意布局 | 本样本未验证这些记法。预览器对未实现的公式形态给出错误提示。 |
| OCR 证据、内部审核记录、整页扫描 | OCR 与审核记录留在原 JSON 和审核流程。整页扫描只在打开原书对照时请求。 |

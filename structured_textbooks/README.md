# 结构化教材项目

逐课保存教材视觉切割、人工审核、教学标签及最终 AI 数据。每本教材直接使用 `书名年份_x语学生_x语教材（年级-分册）_出版社` 作为文件夹名，保留原有中文、标点和出版社拼写。

Lesson 按原书课次以至少三位数字补零，例如 `lesson_001`。各阶段沿用该编号，PDF 页码与印刷页码作为来源信息记录。

| 阶段 | 内容和文件 |
| --- | --- |
| `01_segmentation/` | 每课目录包含待审核的 `content.json`、中文 `review_zh.html` 和哈语 `review_kk.html`。同课界面变体可保存于 `variants/`。 |
| `02_segmentation_review/` | 第一轮审核的原始反馈，按课及审核员保存，例如 `lesson_001/reviewer_01.json`。分别保留各审核员导出文件。 |
| `03_verified_content/` | 处理第一轮反馈、解决冲突并确认后保存的教材内容，例如 `lesson_001.json`。 |
| `04_semantic_labels/` | 基于已确认内容生成的 KLP、题型、难度和关联。 |
| `05_labels_review/` | 第二轮审核的原始反馈，按课及审核员保存。 |
| `06_final/` | 内容和教学标签完成必要的审核、修订和确认后的最终 AI 数据。 |

第一轮审核核对扫描证据、OCR、切割边界、图表、公式和教学关联。第二轮审核复核教学标签和 KLP 关联。阶段目录随实际文件创建。初始切割的待审核状态一直保留在初始数据中，确认后的内容进入相应后续阶段。

原始 PDF、扫描页、OCR、校对 OCR 和 Wiki 继续从仓库历史路径引用。各书 README 记录具体来源，历史实验仍位于 [experiments](../experiments/)。

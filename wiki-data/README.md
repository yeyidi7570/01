# 哈萨克语教材 OCR 与 Wiki 数据

本目录包含四份教材共 539 页的留存 OCR 数据、两轮校对记录、最终校对文字、源页面图、插图资源和 Wiki 结构化候选索引。文本使用 UTF-8，语言标记为 `kk-Cyrl`。

## 从哪里开始

1. 读取 `catalog.json`，找到需要的教材。
2. Wiki 开发优先读取各教材目录中的 `完整原文件名_Wiki.json`。
3. 如只需要整本最终校对文字及坐标，读取 `完整原文件名_最终校对.json`。
4. 如需原始识别输出，读取 `完整原文件名_原始OCR.json`，或 `逐页数据/原始OCR/` 中逐页的原文件。

|---|---|
| `完整原文件名_Wiki.json` | 页面、稳定 ID、最终文字、原始文字关联、坐标、段落候选、题目候选、表单标签及资源索引 |
| `完整原文件名_原始OCR.json` | 整本原始 OCR 页对象的合并容器；`pages` 内不改写原对象 |
| `完整原文件名_最终校对.json` | 整本最终校对页对象的合并容器 |

| `逐页数据/` | 上述五种数据的逐页原文件，按原样复制 |

## 文本和结构的状态不同

**最终文本**来自已保留的两轮校对与主审后数据；本次导出没有重新识别、改写或自动纠正文句。`逐页数据/最终校对/完整原文件名_页NNN_最终校对.json` 是本次导出的文字依据。裁决记录用于追溯，可能不包含后来直接写入最终文件的所有位置或文字微调，应以最终文件为准。

**Wiki 语义结构是自动候选索引，尚未逐题人工定稿。** `question_candidates`、`paragraph_candidates`、`title_candidates`、`lesson_candidates` 以及 `reading_order_candidate` 都明确标注了这一点。

- 题目边界按显式编号和页面位置推测，可能包含旁边的图注或下一块区域，不保证全部题目均被拆出。`question_candidates` 的数量不能当作已确认的题目总数。
- `text_with_line_breaks` 保留行文本与换行，使用候选阅读顺序；复杂多栏、竖排、诗歌、算式和表格应根据坐标与原图复核。没有自动删除行末连字符或把诗歌改成散文。
- 段落候选先参考版面模型的文本区域；未分组文字保留为单行块。没有丢弃未归入段落或题目的有效文字。
- 表格保留区域、文字坐标和源图；`cells: null` 表示尚未转录为经过确认的单元格。未生成猜测的表格关系。
- 公式保留最终行文本和源图；`latex: null` 表示没有生成或人工核对 LaTeX。
- `answer: null` 表示未单独提取或生成答案。原书自带的示例与解题文字仍在行数据中；空白答题区保持在源图和 PDF 中，没有填入答案。
- 子题、选项和知识点标签留待后续整理。空数组表示未结构化，不能据此断言原书没有这些内容。
- 表单字段保留标签、已打印值和位置，`value` 保持空值，不代填成绩、签名或时间。
- 原书特殊用语、印刷错误和未能辨认的装饰文字相关说明见 `proofreading_notes` 及校对记录，不能把备注直接拼成正文。

## 坐标、页码和 ID

- `pdf_page_index` 从 0 开始；`pdf_page_number` 从 1 开始，均为文件中的页序。
- `printed_page_label` 是从页脚候选提取的原书页码，无法可靠提取时为空；不把 PDF 页序冒充原书页码。
- `bbox` 为源页面 PNG 像素坐标 `[x0,y0,x1,y1]`，左上角为原点，x 向右、y 向下。每页记录其 PNG 宽高。
- `bbox_pdf_pt` 为 PDF 页面点坐标，1 点等于 1/72 英寸；按该页实际尺寸换算。
- 页面 ID 例如 `math-2023-grade4-part1:p007`；行 ID 例如 `...:l14`。保留的 OCR 行 ID 与校对补充行 ID 均能在逐页文件中对应。
- ID 在这一数据版本中稳定。以后重新识别或改变页序时，应通过来源哈希和映射表迁移 ID，不要假定新 OCR 行号仍相同。
- 被剔除的假识别文字仍留在 `lines` 中，以 `active: false` 标识，且可回查 `raw_text`。Wiki 展示正文时通常只取 `active: true`。

## 图片完整性

全部源页面 PNG 均保留，因此原书所有可见内容都能回查。单独提取的图片只是模型裁剪和重建 PDF 中的嵌入图像，不声称已把所有矢量图、答题横线和每个装饰元素拆成独立素材。区域裁剪可能包含文字或背景，`assets` 记录了来源和位置。

源 PDF 保留其原始像素与文字层。页面 PNG 是本次 OCR 实际使用的源页面渲染图，清晰度受该渲染尺寸与原稿限制。`来源/原PDF文字层/` 中旧的绝对路径仅是处理历史，不是当前可用资源地址。

## 置信度与追溯

`ocr_confidence` 仅描述原始模型识别置信度，不表示最终文字的可信度，也不是人工校对评分。补充文字没有原始 OCR 分数，值为空。版面模型的 `model_confidence` 同样不表示语义结构已被确认。

`wiki.schema.json` 描述 Wiki 导出格式；原始逐页文件保留其当时的格式。`checksums.json` 为全部交付数据提供 SHA-256 校验；`export-validation.json` 记录本次导出的完整性验证。校验成功只证明数据与资源对应完整，不能替代语义审稿。

## 下载

在仓库首页选择 **Code → Download ZIP** 可一次下载全部资料；也可按需下载单个 JSON。私有仓库需要先登录有权限的 GitHub 账号。

## 文件名规则

教材目录和该教材的所有文件都保留完整原文件名，包括年份、语言、年级、册次和出版社等原有信息，仅追加用途、页码或图片标识。`文件改名对照.json` 记录旧路径和新路径。`book_id`、行 ID、资源 ID 是内部关联标识，保留原值以兼容已有数据；它们不再代替文件名。

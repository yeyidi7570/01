# 必要图示重绘验证

## 适用范围

先按 [图片保留规则](content.md#图片保留判断) 判断图是否承载必要教学信息。对能用确定元素或坐标表示的必要图示执行重绘验证，包括坐标图、统计图、数轴、运动和数量关系示意图，以及位置、角度、配对或步骤可可靠识别的几何图和操作图。只验证与题意、求解或教学说明有关的信息。整课无此类图时记录原因。

## 执行

1. 对照原书提取关系、文字和图例字段，保留原图定位。冻结第一版数据，记录版本或哈希，保持快照原样。
2. 用只接收冻结数据的确定性绘图程序生成验证图，优先 SVG。绘图阶段只提供数据和绘图代码。扫描、裁图、OCR 源文件和原书 PDF 留在比对阶段。绘图代码从字段获得题目专属的点、数值、标注、方向和关系。用简洁的布局默认值可以安排间距或字体。字段缺失时省略该元素或显式标出缺失。
3. 把验证图与同一区域的原图并排，按图型逐项查数值、单位、标数间隔与网格间隔、坐标和比例、图例、箭头起点与方向、位置顺序、距离或括线的两个端点、共享段、留空以及公式下标。图中的定性长短与精确比例分别核对。视觉模型可辅助定位疑点，教材事实依原书证据或有记录的人工确认。
4. 将每个差异归因为数据缺失、数据错误、渲染错误或原书无法确认。回到原书核证后修正相应字段或通用画法，再使用新快照重绘。保留原图、首次重绘、最终重绘以及每轮差异与证据的位置。
5. 题意、求解和教学说明所需的信息均可由数据重现，且与原图核对一致，即可停止。可读性所需的排版、线型或符号替换应记明。线宽、图案和配色等纯装饰差异无需复刻。

## 无法可靠重绘

如果扫描模糊、视角遮挡、刻度无法辨读、原书本身有歧义、结构无法表达，或该图型暂无适用的确定性画法，记录具体限制和已核实字段，保留原图裁剪与待核标记。已确认的部分可单独重绘，未知量留空。审核记录应说明哪些问题仍需人工判断以及为什么。

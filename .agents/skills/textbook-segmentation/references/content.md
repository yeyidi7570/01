# 视觉切割与数据规则

## 来源、页码与身份

优先级为原书扫描、已核实的校对结果、原始 OCR 与布局候选。查实际路径，并记录来源版本、扫描资源 ID、实际 PDF 一基页码、原书印刷页码和对应关系。印刷页码未知时明确标记。以目录、课号、标题、页眉、首尾及相邻页证据核定 Lesson，区分目录起页和真实内容范围，不能按页均分，也不能把下一课、仅供识别的使用指南混入本课。多页 Lesson 处理全页内容，跨页 Module 只有一个父 ID，`page_refs` 覆盖所有片段。记录冲突和边界疑点。

Book → Lesson → Module / Instructional Note / Other。对象保留唯一且稳定的 ID、父 ID、元素、`content_order`、类型、原图页与区域、OCR 证据、不确定项及审核状态。区域用对应源扫描的像素 `[x0,y0,x1,y1]`，原点左上角。阅读顺序按原书实际的文字、公式、表格、图片等相互顺序记录。Other 接住真实但暂不能归类的内容，例如课题、课程说明、带教学内容的非任务元素。保留确有教学价值的插图文字，区分纯装饰、Avatar、边框和背景。

保留原 Lesson ID 与未变化的对象 ID；新 ID 以 Book、真实课号与可确认的原书对象身份建立，不依赖临时顺序、翻译或坐标哈希。首次数据为 `pending_review`，自动建议不视作教师批准。

## Module、Note、Badge 和子题

- Module 是原书明确编号的完整任务。可含多个子题、Badge、文字、图片、表格、公式、Example、Other 或跨页片段。同类可重复。不得因子题、Badge 或分页拆成多个父题。核对子题的连续性及完整嵌套。
- 本项目哈语教材独立 Note 使用 `instructional_note`，原书标签字段为 `instructional_note_badge`。已确认范围是 `ЕСІҢДЕ САҚТА!`、`ОСЫЛАЙ ТАЛДА!`、`КАЛЬКУЛЯТОР`。Note 与 Module 是 Lesson 内同级单元；背景色或无编号本身不足以判定。证据不足留作 Other 或待核。其他教材的模板如有差异须以原图及确认规则为依据。
- 已知 Module Badge 包括 `ЖАҢАНЫ ОҚЫП-ҮЙРЕНУ`、`СЕН ЗЕРТТЕУШІСІҢ`、`ШЫҒАРМАШЫЛЫҚ ЖҰМЫС`、`ЖҰПТЫҚ ЖҰМЫС`、`ТОПТЫҚ ЖҰМЫС`、`МАТЕМАТИКА КҮНДЕЛІКТІ ӨМІРДЕ`、`ӨЗІНДІК ЖҰМЫС`、`ҮЙ ТАПСЫРМАСЫ`。以原书使用说明及本课印刷为准。可无 Badge、同胶囊多 Badge、同课多胶囊、同任务不同位置、标签重复；记录原文、位置及作用对象 `scope_ids`，范围不明须标待核。同一个 Badge 不能据此拆题。独立、双人或小组是组织方式，与难度无直接对应。
- 明确标为 `ӨЗІҢДІ ТЕКСЕР` 的自我检测课可让 Module 显示继承标签，记录 `badge_origin = lesson_inherited` 和 Lesson 证据。其他印刷 Badge 记录为原书来源。缺 Badge 不构成自我检测证据。
- 子题索引 `subtask_label` 使用哈萨克语大写西里尔字母，如 `3А`、`3Ә`、`3Б`。`Subtask Number` 的 `text_kk` 按原书显示，确认原书使用小写 `а)`、`ә)` 时，保留原样并记录相同的 `printed_label_kk`。看清字形再确认大小写。正文检查拉丁 A 与西里尔 А 等形近字。ISBN、出版信息、外文名称、数学变量及原图证明的例外保留合法拉丁字符，禁止全局盲替。

## 文字、公式、表格、图像

- 文字完整保留题目要求、条件、子题、枚举、列表、单位和原书逻辑段落。可读文本合并排版断词和无意义换行，有意义的连字符、换行和分组保留。
- 公式保留数学意义及版面，包括运算符、单位、上下标、竖式、进借位、计算示范的二维位置。依据扫描确认结构；缺值和作答空位保留，不补答案。Example 限于原书明确发挥演示或样例功能的内容，不能仅凭等式算完就判断。
- 竖式的字符位置体现数学关系时，以 `vertical.layout` 记录数位列、行、运算符、单位、横线跨度、留空和原书确有的进借位标记。裁图仅供对照。Example 用 `worked_sequence.steps` 和 `relationships` 保留文字说明、连续算式及换算的顺序和联系。
- 表格记录表头、行列、空白格、合并格、跨行跨列、格内多行、数字和公式。多行格仍是一格。无法可靠还原时嵌入原图、保留裁剪区域和待核标记。
- 信息性图片保留裁剪资源、来源页坐标以及有依据的 `structured_description`。逐项记录箭头方向、连线、大括号、对象与数量关系；区分原书直接可见信息、结构化解释和不确定推断。不可把图中 OCR 数字线性排列当作完整关系，不解题。两版显示裁图及对应语义说明。
- 装饰部分只分割必要教学内容，原扫描在审核页仍应完整可见。

## OCR 与教学关联

逐条区分字符识别（哈语字母、混用、大小写、数字或符号）、排版整理（真实断词或无意义 OCR 分行）以及结构识别（表格、竖式、括号关系、归属或顺序）。保留原始 OCR、已有校对 OCR、本轮建议值、类型、理由和原图定位，稳定链接到对应对象。原始 OCR 与正式校对文件只读，建议值不自动标为通过。

教学关联方向以 `from_id → to_id` 记录。

| 关系 | `from_id` | `to_id` | 书面证据 |
| --- | --- | --- | --- |
| `supports` | 提供方法或知识的 Instructional Note 或其内容 | 受支持的 Module 或其内容 | 说明给出适用于该题的方法或概念。例如 Lesson 003 第 15 页，说明给出从高位比较多位数的方法，Module 2 要求比较数字。 |
| `uses_as_material` | 使用材料的 Module 或其内容 | 所属 Module 之外的明确材料，例如另一 Module、独立 Instructional Note 或它们的内容 | 题目明确引用该材料，且可从题目和原图定位。例如 Lesson 012 的 Module 2 引用了独立 Instructional Note 中的换算材料。 |

按端点沿父子结构所属的 Module ID 判断边界。同一 Module 内的 Informative Image、Table、Formula、Text 或其他元素通过父子结构表达包含关系。即使题目写明“看图”，或一个子题引用同一 Module 的另一个子题中的材料，也不建立 `uses_as_material`。材料关系允许跨到另一个 Module 或没有 Module 归属的独立材料。

依据原图核对语义，记录两个端点的来源位置、关系理由和不确定性，允许多对多。单凭位置相邻无法建立关系。校验程序检查端点类型、自连、方向和材料引用是否跨越 Module 边界。跨边界的实际引用仍需原书证据。`supports` 继续核对独立说明对任务的知识或方法支持，独立 Instructional Note 保持视觉和数据的同级关系。

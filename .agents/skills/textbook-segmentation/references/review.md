# 双语离线审核合同

两个 HTML 各自离线运行，内嵌相同的教材、扫描、裁图和审核逻辑。中文页面额外显示参考翻译。中文翻译反馈可由中文版提交，两版均保留兼容的记录。

## 审核单位与进度

- 结构类型一律显示英文。沿用 Module、Instructional Note、Subtask、Example、Badge、Text、Formula、Table、Informative Image、Other、Module Number、Module Badge、Instructional Note Badge、Subtask Number 和 Teaching Link。两版的审核动作、状态和帮助文字各自本地化。JSON 类型代码和稳定 ID 沿用教材数据。
- 内容对象的实际正文、公式、表格、图片、标签等各有一组相邻的通过、有问题和无法判断。Module、Instructional Note、Subtask、Example 等可作为分组标题。分组自身有独立正文或标签时，其内容可单独审核。仅提供子项来源的裁图属于分组证据。
- 分组优先显示有问题、无法判断、审核中、通过。所有实际子项和自身内容都通过且无待处理的结构问题才汇总通过。空容器不产生待审核任务。任何分组或页面的通过都不改变子项的状态。
- 分组提供独立的结构问题入口，覆盖边界、漏切、归属、阅读顺序、跨页和 Badge 作用范围等。切割完整性以页面为单位审核，支持框选遗漏。总进度和「未审核」筛选纳入内容、页面完整性及确实需要审核的结构项。待复核的结构项在相应内容旁显示确认按钮，筛选时保留其子内容作为对照。
- OCR 修正建议继续保存来源、原值、建议值、类型和对象 ID。通过表示认可当前展示内容。历史 OCR 确认记录始终可导入和再导出，自动建议不再产生审批动作或进度指标。

## 阅读与反馈

- 左侧显示扫描、切框、缩放及页码，右侧连续显示教材内容。保留原书顺序、跨页 Module、合并单元格、原印空白、竖式和换算关系。按数位及最小单位对齐竖式，保留运算符、横线和结果换算。连续示范可同时显示整组裁图和分组说明。
- 原扫描仍显示完整页面。图示卡片只显示有必要信息的图片，审核时对照题干确认其作用。省略的配图可在左侧原扫描查看。
- 含上下式分数的 `problem_statement` 在中哈审核页预览为连续段落。行内分数和独立分数审核卡均用原生 MathML，上下式和原图裁剪可分别核对。预览复用子对象的数据和审核状态。
- 默认只显示内容、中文参考翻译、必要的 Badge 作用范围、合并后的实质性疑点与审核动作。原始 OCR、坐标、对象 ID、内部数据和普通自动整理过程保留在内嵌数据中。短提示应指出真正需要老师判断之处。
- 支持对象定位、同步开关、进度和筛选。问题表单随内容打开并保存，提供 OCR、数学布局、表格、图片关系及结构等定位和修改输入。保存后保留当前位置。
- 审核员、本地草稿和 JSON 导入导出共用版本与身份校验。历史版本的记录保留原身份。已明确等同的内容可沿用记录，改变的内容需复核。父级旧通过保留为历史，不能继承给未审核的子项。问题和无法判断记录不得被静默覆盖。找不到安全对应关系的记录需标记待确认。已处理的问题只记录在修订元数据中，保留原记录。
- 多轮修订通过 `review_revision.ancestors` 记录各早期版本的对象和等同范围。每个早期版本的等同对象须在所有中间版本中保持等同。导入和再导出时保留原版本与记录 ID。旧版附带的识别修正审批不作为内容审核冲突。
- 竖式审核先显示有独立二维数据的重建结果，再显示带「原书裁图（对照）」标签的原图证据。不能用原图替代重建结果，也不能靠普通字符串空格对齐。证据不清的格子、进借位或关系须标注待核，展示可以确认的结构。
- 「无法判断」记录的原备注在卡片中标为「人工待审核原因」，并随审核 JSON 保留，供后续专业复核。

## 每课断网实测

用 `file://` 打开双语产物并拦截网络。检查扫描、切框、滚动定位与跨页分组。用单个和多个 Formula 的 Example、含子项的 Instructional Note 和空容器核对按钮数量和父级汇总。逐项对照重建竖式与原书裁图，核对数位、单位、符号、横线范围、空位、进借位和换算顺序。检查重要 Badge 疑点、合并与空白单元格、页面遗漏框选、局部修改。核对原始审核包导入、新包双语交叉导入及草稿恢复，确认记录身份和问题状态保留。现有历史产物可用静态检查读取，重新生成时使用当前模板。

Teaching Link 的卡片与编辑器都按关系显示端点角色。`supports` 是「提供方法或知识 → 受支持的任务」，`uses_as_material` 是「使用者 → 所属 Module 之外的引用材料」。在中哈两版测试适用的卡片、端点定位和切换关系后的角色。保存时应拒绝倒置的支持关系、同一 Module 内的材料关系（包括不同子题），并接受有证据的跨 Module 或独立材料引用。导出使用 `from_id`、`to_id` 和 `relationship`。旧审核记录继续按原版本导入和再导出。运行 `python -m unittest discover -s .agents/skills/textbook-segmentation/scripts -p 'test_teaching_links.py'` 校验数据方向和 Module 边界。

运行 `python -m unittest discover -s .agents/skills/textbook-segmentation/scripts -p 'test_image_retention.py'` 回归检查第三册第 81 课的必要图示、被省略的配图、完整扫描和历史审核映射。其他课仍逐图对照原书判断。

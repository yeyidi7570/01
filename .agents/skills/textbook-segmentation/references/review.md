# 双语离线审核合同

两个 HTML 分别独立打开，必须内嵌同一教材 JSON、扫描资源、裁剪结果和交互脚本。禁止 CDN、在线脚本、外部 JSON、图像路径或服务端依赖。共用审核逻辑、状态与内部问题代码，不依语言改变审核权限。优化体积须保持可校对清晰度。

- 中文版使用中文操作界面，在哈语原文旁逐段、逐子题和逐格提供中文辅助翻译，包含 Badge 与图片关系说明；疑译可标识。哈语版使用哈语界面、哈语原文和哈语结构化说明。翻译与原文独立保留，翻译问题使用独立类型，中文入口可专属但记录结构兼容。不要用翻译推出原书未给出的答案。
- 桌面双栏。左侧扫描页可切换、缩放、显示 Module、Note 和元素的分别着色切框，选中时高亮，可框选漏切或发起页面级反馈。右侧默认完整连续问卷，按课本顺序渲染主卡片，保留子层级、列表、表格和公式二维布局。课程标题、课前说明及 Other 也有入口。跨页 Module 单卡、多页定位。右滚同步左侧页和区域，左侧框点击定位右侧卡或内项并短暂高亮；避免互相触发滚动，手动缩放期间尊重浏览位置，必要时提供同步开关。
- 主卡底部独立的通过、有问题和无法判断。问题表单在当前卡片内，支持类型、备注和可定位的原文/结构更正。可对元素单独审核。状态为 `unreviewed`、`approved`、`issue`、`unable_to_verify`；跳过保持未审核。保存就地更新，保留卡片，不自动跳转。自动收起可选且默认关。整卡通过覆盖普通未审核子项，已有子项问题、无法判断和待单独确认的证据不得被覆盖，父卡显示提示。提供进度、未审核/有问题/无法判断的筛选、课内跳转和回顶。
- 默认显示原图、哈语可读内容、中文辅助层（仅中文）、结构化图/数学、OCR 提示及独立审核入口。OCR 行号、坐标、原始与校对 OCR、内部字段和来源证据放入可展开区。
- 分类至少覆盖漏切、多切、边界、归属、类型、Badge、Note、OCR 字符、哈语子题编号、断词换行、公式、表格、图片关系、阅读顺序、教学关联、中文翻译和其他。漏切可保存所选区域或页信息。
- 支持条件允许时的本地草稿、导出与导入审核 JSON、恢复进度。记录包含对象 ID、教材及 Lesson ID、数据版本、原值与新值、问题类型、来源区间、审核状态、备注、记录身份。不同审核员的反馈保持独立并显示冲突。旧版本只可匹配可证明等同的对象，拆分、合并或语义改变的对象提示人工确认。保留原始反馈，禁止静默迁移。

## 每课断网实测

在独立目录以 `file://` 打开各语言版并拦截网络。核对扫描图、彩框、公式、表格、图片和全部卡片。测试逐卡通过后原位、行内报错和不同卡片不串改、OCR/子题修正、左框点击、右滚翻页、跨页范围、漏切保存、暂存草稿、两种语言导出后交叉导入、已有问题在整卡通过后仍存在。比较导出的版本与对象 ID；失败或未跑的项目明确标明。静态检查不能替代浏览器交互验证。
